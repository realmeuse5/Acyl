What is Acyl?

Acyl is a programming language designed for simplicity and explicitness. It has strict syntax to eliminate any assumptions made by the compiler.

Uses explicit right to left assignment.

Built-in array library for managing dynamic arrays.

Block based execution using mandatory keywords.

Some unconventional syntax.

main.ac 
#acyl

// Code starts here
fn main()
    int num -> 10
    str user -> "Developer"

    array.str items -> ["Acyl", "Programming"]
    array.add(items, "Language")

    acyl.out("Hello, " + user)
end
